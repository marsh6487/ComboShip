The historical seasonal source object `2d89cbf6...` was not recovered. This
candidate deliberately recreates the routing capability. It is generic: another
modder can package a compatible vanilla Link or custom-model family without
editing the build. See `docs/modding/seasonal-outfits.md` for the public format.

Each outfit retains its accepted rig, bone layout, geometry and texture pixels.
Its private skeleton resource is the entry point to its own limb display lists;
it is not a new animation or rerig. Weapons/shields and other common gear keep
shared routes. Outfit-specific hands/composite wrappers stay private. Off,
inactive seasons, or absent/incompatible variants keep the ordinary model
selection; forced forms and remote model choices retain their priority.

The first converted set is adult Din Spring, Autumn and Winter from the accepted
ModelOnly POC3 archives. The separate test-pack ZIP includes those three private
archives, one shared gear dependency, installation notes and full validation.
Summer and young seasonal variants are not invented; their missing slots use
the ordinary fallback. Run animations remain separate. The conversion changes
paths/references only and reproduces original resources on reverse rewriting.

Player weighted support is independently reusable. Current rigid Din/outfit
packs stay rigid. A future weighted model must provide compatible inverse binds,
quantized two-bone weights and weighted companion meshes; the engine does not
automatically import or deform an arbitrary FBX. Missing/invalid metadata or
unsafe matrix allocation/packing uses rigid fallback meshes.

Use these assets only with a build containing this candidate. Remove the older
fixed-path seasonal test overrides, retain the normal base model, install the
converted packs according to their README, and select the outfit set. Confirm
Off/no-season/missing-pack fallback, a full season cycle and return, both ages
and games, scene transitions, held equipment and first-person views, Alt settings
and forced-form priority. Test the reported shop audio with the actual music
pack before marking that symptom fixed.

Authored Prelude wall/bomb actor cleanup remains a separate deliverable and is
not introduced by this pass. No publication or remote source push is performed.
