Clear wording says that defeating the first named enemy rewards the inserted item. ITEM and ITEM_AREA select this action text; ITEM_AREA does not invent a witness dungeon as the location. English/German/French frames preserve the native family name and item insertion token. These location keys are distinct from soul item hint keys.

Focused tests execute actual native Hint::GetHintText, HintText and CustomMessage storage, Location::GetHint, and require 43 unique identities and correct type/item tokens.
