# Authored OoT Clock route probe

Run `python3 -B tests/authored_clock/run_tests.py` with the checkout's normal C++ dependencies available (`nlohmann/json.hpp`, spdlog and imgui).

This compiles production callbacks, exact Clock exporter branches, owner-routing fragments, both complete foreign compositors, their actual custom GI drawers and the shared NEI renderer against each game's real headers. MM's real `gSPDisplayList` wrapper also executes, preserving explicit foreign paths as deferred filepath commands. Resource availability, matrix/graphics allocation and unrelated item handlers are substituted at the existing NEI fixtures' boundaries; unrelated compositor branches assert if reached. The baseline exporter excerpt is preserved from `e22bcb222dcd06d18567cbbb47087d3d5979be96` to reproduce its Stone of Agony result.

The probe checks native OoT registration/callback; native MM `RI_OOT_CLOCK` dispatch; both foreign descriptors; preservation of explicit MM routes and qualification of OoT routes; `.04` model scale; the existing Hourglass shimmer palette and ItemEffects toggle; Alt flags; and CPU matrix, owner scope and grayscale cleanup. The six MM half-day cases continue dispatching to their original `DrawClock` function. The shared header compiles for both original hosts and combined builds.

Each Clock route must submit its own `gNeiClockGlassTexDL`, then the native five-command interpolated tile operation, then `gNeiClockGlassDL`, even with ItemEffects disabled. The texture load and geometry must use the native owner scope or the same explicit foreign owner. Ten hand-derived phases cover normal motion, the 127-to-128 interpolation seam, the 128-tick repeat and unsigned frame wrap. The probe rejects any RSP segment command on either stream. Tight arena cases retain the opaque body without orphan texture/scroll commands, and exhaustion queues nothing. A separate unrelated custom OPA/XLU recipe retains its two original submissions without any glass preparation.

The complete foreign lookup/cache/award queues remain covered by existing lifecycle tests. This probe executes each complete compositor with resolved Clock data, including its optional shimmer dispatch; it does not reproduce foreign lookup or award queues. Resource traversal, lens confinement and serialized material restoration belong to the authored asset tests. No fixture proves actual GPU appearance, pickup framing, menu transitions or runtime Alt resource selection; those remain configuration-specific game checks.
